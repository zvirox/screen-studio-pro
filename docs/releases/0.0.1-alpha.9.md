# Release notes — v0.0.1-alpha.9

**App version:** `0.0.1+alpha.9` (semver-equivalent to the tag `v0.0.1-alpha.9`; Tauri bundlers reject `-` in version strings).
**Status:** Strict Alpha Track — prerelease build.

This release applies DESIGN.md v3.2, "Quiet Studio Instrument", across the whole UI. It follows alpha.8's offline asset fix and does not change capture, encoder, IPC, or production behavior.

---

## Changed

- Sentence-case overline labels replace uppercase tracked labels throughout Record, Settings, Library, HUD, and PiP.
- Neutral surfaces and hairlines replace specular glass glows; shadows and blur are restrained.
- Studio Burgundy is reserved for the primary Record action and true selected/live states; decorative accent hovers, badges, and sort labels are neutral.
- A fixed `text.on-canvas` token keeps preview-canvas copy readable in both themes.
- One easing curve governs all transitions; looping non-live motion, bouncy easing, and `transition-all` are removed.
- The duplicated bottom preset selector is removed; the inspector remains the single preset control.
- README screenshots are refreshed from the mocked-IPC harness.

## Verification

- Typecheck, lint, 320 frontend tests, production build, and diff checks passed before publication.
- Release and installed-system verification will be recorded below after the alpha.9 bundle is published.

## Validation boundaries

- UI-only design change; recording, capture, encoder, IPC, and storage behavior are unchanged.
- README previews remain mocked-IPC frontend renders, not packaged-app recording sessions.

See the [README installation guide](https://github.com/zvirox/screen-studio-pro/blob/v0.0.1-alpha.9/README.md#-installation) for package formats and commands.
