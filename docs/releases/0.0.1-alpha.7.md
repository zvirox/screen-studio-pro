# Release notes — v0.0.1-alpha.7

**App version:** `0.0.1+alpha.7` (semver-equivalent to the tag `v0.0.1-alpha.7`; Tauri bundlers reject `-` in version strings).
**Status:** Strict Alpha Track — prerelease build.

This release fixes the persistent in-app `GDBus.Error:org.freedesktop.portal.Error.NotAllowed: This call is not available inside the sandbox` error observed with alpha.6. The app remains on GNOME 49 and is otherwise unchanged.

---

## Fixed

- **Grant network access to the Flatpak sandbox.** `xdg-desktop-portal`’s ProxyResolver returns `NotAllowed` unless the app has network access; alpha.6’s talk-name permission was necessary but not sufficient. The manifest now includes `--share=network`, allowing WebKitGTK’s normal proxy resolution to complete.
- The Flatpak manifest retains the GNOME 49 runtime, the `--talk-name=org.freedesktop.portal.ProxyResolver` permission, and all alpha.6 packaging protections: GNOME 49 + SDK, retained tray libraries, no WebKit sandbox/compositing/software-rendering overrides, and the release-time library/startup gates.

## Verification

- Release runs for alpha.5/alpha.6 passed; the new alpha.7 CI and release runs are recorded below.
- Installed alpha.6 SHA-256 matched GitHub before installation.
- Controlled installed-system launches: **3/3 survived the full 20-second window**, with explicit `flatpak kill com.zvirox.screenstudiopro` after each run.
- The verified alpha.7 bundle is installed into the existing system installation; the app is expected to remain error-free in the normal window.

## Validation boundaries

- Packaging-only changes: no recording, capture, encoder or production UI behavior changed.
- Startup checks are not recording-session validation. Full recording validation remains open.

See the [README installation guide](https://github.com/zvirox/screen-studio-pro/blob/v0.0.1-alpha.7/README.md#-installation) for the other package formats and exact commands.
