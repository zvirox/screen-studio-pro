# Release notes — v0.0.1-alpha.6

**App version:** `0.0.1+alpha.6` (semver-equivalent to the tag `v0.0.1-alpha.6`; Tauri bundlers reject `-` in version strings).
**Status:** Strict Alpha Track — prerelease build.

This release fixes the in-app `GDBus.Error:org.freedesktop.portal.Error.NotAllowed: This call is not available inside the sandbox` error observed with alpha.5. The app remains on GNOME 49 and is otherwise unchanged.

---

## Fixed

- **Allow the existing WebKitGTK proxy-resolution portal call.** The GNOME 49 WebKitGTK stack uses `org.freedesktop.portal.ProxyResolver.Lookup`; the Flatpak sandbox previously rejected it because the manifest did not grant that portal interface. The manifest now includes `--talk-name=org.freedesktop.portal.ProxyResolver`.
- The Flatpak manifest retains the GNOME 49 runtime and all alpha.5 packaging protections: GNOME 49 + SDK, retained tray libraries, no WebKit sandbox/compositing/software-rendering overrides, and the release-time library/startup gates.

## Verification

- Release run `45030703885` passed both package jobs, including the retained Flatpak library and 20-second startup gates.
- Installed alpha.5 SHA-256 matched GitHub before installation.
- Controlled installed-system launches: **3/3 survived the full 20-second window**, with explicit `flatpak kill com.zvirox.screenstudiopro` after each run.
- The verified alpha.6 bundle was installed into the existing system installation; run the bundle’s release-time gates again before beta.

## Validation boundaries

- Packaging-only changes: no recording, capture, encoder or production UI behavior changed.
- Startup checks are not recording-session validation. Full recording validation remains open.
