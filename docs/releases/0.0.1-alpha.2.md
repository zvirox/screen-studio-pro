# Release notes — v0.0.1-alpha.2

**App version:** `0.0.1+alpha.2` (semver-equivalent to the tag `v0.0.1-alpha.2`; Tauri bundlers reject `-` in version strings).  
**Status:** Strict Alpha Track — prerelease build.

These release notes document the **Wide-Window Floating Studio Overhaul** (DESIGN.md v3.0), inspired by modern studio software (Camo Studio, Meld Studio, PRISM Live Studio).

---

## Highlights

1. **Wide-Window Floating Studio Overhaul (DESIGN.md v3.0):**
   - Eliminated the square 1:1 letterboxed preview box in favor of an expansive **16:9 widescreen hero preview canvas** (`aspect-video rounded-lg hero-canvas border border-line-glass shadow-elev-float`).
   - Symmetrical floating glass islands (`surface.glass-strong` with `16px` corner radius, specular 1px border, and ambient drop shadows).
   - Deep Obsidian Slate neutral grounds (`bg.canvas` `#0A0B0E`, `bg.raised` `#12141A`, `surface.solid` `#181A22`) designed for high contrast and zero desktop glare.

2. **Integrated Studio Titlebar (NavBar CSD):**
   - Window control dots, centered 3-tab segmented view capsule (`Record` | `Library` | `Settings`), live telemetry badge (`1080p60 VAAPI`), and 40px primary Record pill CTA button.

3. **Left Floating Capture Inspector Deck (`CaptureInspector`):**
   - 300px fixed glass island containing:
     - 3-way segmented source switcher (`Monitor` | `Window` | `Region`) with quick hotkeys `1`, `2`, `3`.
     - Active source resolution badge (`1920×1080 · 60fps`).
     - Camera PiP controls: device popover, circle/rounded shape switcher, 4-corner snap grid, 160–320px size slider, and self-insert toggle.
     - Plain-language quality preset dropdown selector and hardware encoder status badge (`VAAPI (Hardware)` / `CPU Fallback`).

4. **Sub-Canvas Floating Audio Mixer Deck (`AudioMixerDeck`):**
   - Positioned symmetrically below the 16:9 hero canvas (Meld Studio style).
   - Vertical channel cards for **Mic** and **Desktop Audio**:
     - Live stereo peak/RMS meter bars with dBFS readouts (-60 to 0 dBFS with -6 dB compression zone).
     - Active DSP badges (`[RNNoise]`, `[Gate]`, `[Auto-Ducking]`).
     - Volume gain faders (0–100%) and high-contrast tactile Mute buttons.
     - Device selector popovers and mic silent hint.

5. **Right Takes & Presets Gallery (`TakesGallery`):**
   - 260px floating glass card with fast toggle between Takes and Presets (Camo Studio style).
   - 16:9 thumbnail preview cards with duration chips (`02:14`), size badges (`48 MB`), and hover quick-actions (Open detail drawer, Reveal in file manager, Copy path).
   - Quick scene presets list with hotkey badges (`F1`, `F2`).
   - Empty state illustration and "Open Library →" navigation.

6. **Responsive Layout Polish (`RecordView`):**
   - Tri-panel studio integration with responsive collapse toggle for viewports narrower than 1120px.

7. **Release Timeline Codification:**
   - Updated `PLAN.md` and `PRD.md` establishing the three-tier lifecycle:
     - Strict Alpha: Phases 0–9 (`v0.0.1-alpha.1` $\rightarrow$ `v0.1.0-alpha.x`)
     - Strict Beta: Phases 10–14 (`v0.9.0-beta.1` $\rightarrow$ `v0.9.x-beta.*`)
     - First Stable Release: Post-Phase 14 (`v1.0.0`)
